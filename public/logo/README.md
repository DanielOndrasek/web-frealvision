# Logo F·Real Vision

- `frealvision.svg` — vektor, černý, včetně „s.r.o.“. Pro e-mail, tisk, dokumenty.
- `frealvision-inverzni.svg` — totéž bíle, na tmavý podklad.

Web logo nekreslí z těchhle souborů, ale z `components/layout/logo-paths.ts`
(stejná data), aby šlo přebarvit přes `currentColor`.
